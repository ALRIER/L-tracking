# L-Tracking

Structured nutrition, weight, body measurements and exercise logs.

**PUBLIC REPOSITORY:** Nutrition and health-related information here is visible to everyone.

- `nutrition/daily/`: individual records for Days 1–27.
- `nutrition/daily_summary.csv`: cumulative daily metrics.
- `nutrition/food_references.csv`: nutrition label references.
- `body/`: weight and measurements, blank until substantiated observations are supplied.
- `activity/`: self-reported exercise.
- `docs/methodology.md`: data provenance and corrections.

Day number is not a verified calendar date. Numeric values are approximate unless a label was provided.
